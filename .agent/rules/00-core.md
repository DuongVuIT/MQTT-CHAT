# Core Rules

- Understand before modifying: scan repo, read entrypoints, never guess.
- Never knowingly leave the repository broken (lint/typecheck/test/build must pass).
- Do not remove existing working behavior without technical justification.
- No fake implementations; no TODO features marked as done.
- Fix root causes, not symptoms. No random multi-file "try things" edits.
- Verify after changes: run quality gates before declaring done.
- Respect architecture boundaries (see 01-architecture.md).
